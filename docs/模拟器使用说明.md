# 直连型主机模拟器使用说明

直连型主机模拟器（`直连型主机模拟器V1.20.exe`）是模拟恒博报警主机的测试工具，用于在**没有真实设备**时调试接警中心、`httprelay` 及其他对接程序。它基于与真实主机固件同源的协议栈实现（`libuvmachine` + `libademco`），模拟器发出的报文真实主机同样会发，可以放心用于联调。

适用读者：接警中心/平台开发人员、现场调试人员。

## 一、快速三步跑通

1. 填写「接警中心地址」与端口：填写你要对接的服务端（如 `httprelay` 所在机器的 `IP` 与其 `TCP` 监听端口）；
2. 点击「连接」：模拟器将自动上报主机类型与当前状态，随后周期发送心跳；
3. 在「防区信息」列表中选中一个防区，点击「触发」（或直接双击该防区）：接警端即收到该防区的报警事件。

对接 `httprelay` 时，`httprelay` 窗口应出现 `C:`（收到主机报文）与 `OUT:`（转发出的 `JSON`）日志，即链路全通。

## 二、界面分区

### 1. 连接参数区（左上）

| 控件 | 说明 |
| ---- | ---- |
| 接警中心地址 / 端口 | 目标接警中心的 `IP` 与 `TCP` 端口 |
| 主机账号 | 模拟主机的 `acct`，如 `861234567890` |
| AdemcoId | 安定宝 `ID`，一般从 `1` 递增 |
| 主机类型 | 下拉选择模拟的型号（网线、`GPRS`、液晶、三区段等），影响能力差异（如信号强度是否可上报） |
| 主机状态 | 离家布防 / 留守布防 / 撤防 / 设置，四选一，连接后上报当前状态，切换时上报新状态事件 |
| 主机密码 / 撤防半布防时校验 | 密码默认 `123456`；勾选「校验」后，收到接警中心的撤防/留守布防命令时会校验密码，错误则上报 `1701`（撤防密码错误）——用于测试控制指令的密码流程 |
| 信号强度 | 滑条调节，仅支持信号强度上报的型号可用 |
| 连接 / 断开 | 建立或断开 `TCP` 连接；断开后接警端收到掉线（`httprelay` 下为 `1944` 事件） |

### 2. 防区信息区（左下）

- 「随机生成」：随机生成一批防区（编号、无线地址、类型）；
- 「+ / -」：添加 / 删除防区。添加对话框中填写防区号、无线地址（下拉选择）、防区类型（下拉选择）；
- 「触发」或双击列表项：让选中防区上报一次报警事件，事件码由防区类型决定（门磁为盗警、烟感为火警等）。

### 3. 事件模拟区（右上）

手动构造任意事件报文，弥补防区触发覆盖不到的场景：

| 控件 | 说明 |
| ---- | ---- |
| Event | 事件码下拉（全部已知事件） |
| Zone | 防区号（`0` 为主机自身事件） |
| GG | 区段号，三区段主机用 `1~3`，其余 `0` |
| xdat | `xdata` 附加数据（如信号强度、透传数据），勾选 `hex` 按十六进制输入 |
| 长度格式 | `2 hex`（两位十六进制长度）或 `4 dec`（四位十进制长度） |
| 发送 | 将上述内容打包为一帧报文发出，报文同时显示在「generated packet」只读框，方便核对 |
| 定时 + ms | 勾选后按设定的毫秒间隔自动重复发送当前报文（压力测试用，取消勾选即停） |
| 1/2/3：布防 | 三区段主机专用：对第 `1/2/3` 区段单独布防 |

### 4. 日志区（右侧）

- 收发日志带毫秒级时间戳；点击某条日志，下方只读框显示该帧报文完整内容；
- 「清空」清空日志；「导出」将日志导出为 `txt` 文件（用于发给对接方分析）；
- 「generated packet」框实时显示最近发出的报文。

## 三、连接后的自动行为

模拟器与真实主机一致：

- 连接建立后自动上报主机类型与主机状态（真实主机还会上报固件版本）；
- 周期发送心跳（`NULL` 包），默认约 `118` 秒；
- 收到接警中心的 `ACK` 自动处理；收到布防 / 撤防命令会执行（状态切换并上报新状态事件），密码校验开启时校验密码；
- 断线后可点「连接」重连，接警端应看到上线事件（`httprelay` 下为 `1946`）。

## 四、常用联调场景

1. **无设备验证链路**：模拟器 → `httprelay` → 你的接收端，见[快速上手](快速上手.md)；
2. **测试控制指令**：接收端 / `curl` 调用 `httprelay` 的 `/control` 下发撤防，观察模拟器状态切换与回报事件；开启密码校验后用错误密码，应收到 `1701`；
3. **测试掉线处理**：点「断开」，验证你的平台收到掉线事件、控制返回离线错误；
4. **测试不同型号**：切换「主机类型」重连，验证平台对不同型号的兼容性；
5. **压力测试**：定时发送（如 `1000ms`）+ 随机防区批量触发，观察接警端处理能力。

## 五、配置管理

- 配置以 `ini` 文件保存，包含中心地址、账号、类型、防区表等全部参数；
- 菜单「保存」写入当前配置文件；「另存为」可存为新文件（便于为不同项目维护多套配置）；「关闭」= 断开并保存；
- 程序记住上次使用的配置文件，下次启动自动加载。

## 六、注意事项

- 本模拟器为 `32` 位程序，`httprelay` 的 `x86` 目录内附带的即为本工具；
- 模拟器与真机的主要差异：无线探测器侧的行为（探测器信号重发、电池电量等）不在模拟范围，需按[对接说明](对接说明.md) `FAQ` 的真实机制设计平台逻辑；
- 模拟器与真机一样会因接警中心 `ACK` 应答不正确而重连重发，若观察到反复重发，请先检查接警端的 `ACK` 实现（见[协议文档](README.md) `ACK` 应答规范）。
