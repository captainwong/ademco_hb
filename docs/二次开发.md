# 二次开发

对接前请先阅读[对接说明](./对接说明.md)选择路线；本章介绍开发、联调阶段的环境搭建与调试手段。

## 环境搭建

1. 没有主机

    在 `Windows` 上运行 `直连型主机模拟器` 模拟主机（从 [releases](https://github.com/captainwong/ademco_hb/releases) 下载，位于 examples 压缩包内），运行 `server_demo` 监听主机连接；走 `HTTP` 转发路线则运行 `httprelay`，参见[对接说明](./对接说明.md)。

2. 有网络模块主机，无公网IP

    使用 网络模块配置工具将主机的接警中心IP配置为局域网内服务器IP，在服务器运行 `server_demo` 监听主机连接

3. 有主机，有公网IP

    使用 `手机APP` 或 `网络模块配置工具` 将主机的 `直连型接警中心` IP/端口 配置为公网地址，公网服务器执行 `server_demo` 监听主机连接。`server_demo` 可以在 `ubuntu` , `centos` 或 `macOS` 下编译，执行 `build.sh` 即可。

## 数据查看

1. 可以用 `wireshark, tcpdump` 等工具抓包分析
2. `server_demo` 与 `httprelay` 均有命令行输出（`httprelay` 会打印收发的原始协议帧 `C:`/`S:` 及每次转发的 `JSON`）
3. releases 中的 `AdemcoParser.exe` 可用于解析协议帧
